# Civitas Lab v0.1.0

Civitas Lab v0.1.0 establishes a narrow, reproducible baseline for spatial
evolutionary-game experiments in modern Java.

## Highlights

- Deterministic synchronous spatial Prisoner's Dilemma engine.
- Dependency-free mathematical core with flat primitive lattice storage.
- Strict JSON experiments, stable seeds, checksums, tables, snapshots, and
  charts.
- Reproductions of the Nowak-May frequency profile and bounded kaleidoscope.
- A predeclared 1,200-run robustness grid with paired replicates.
- ODD model documentation, explicit limitations, verified references, and
  citation metadata.

## Assets

- `civitas-lab-0.1.0.jar`: self-contained Java 25 command-line application.
- `civitas-lab-0.1.0-results.tar.gz`: complete raw outputs for the frequency,
  kaleidoscope, and robustness experiments.
- `SHA256SUMS`: checksums for both release assets.

The compact figures and aggregate tables are also versioned under
`docs/results/v0.1`.

## Scientific Boundary

This release reproduces one abstract synchronous lattice model. Its results do
not predict human cooperation or establish that spatial structure universally
promotes cooperation. See the ODD description, experiment protocol, and
limitations before interpreting the outputs.
