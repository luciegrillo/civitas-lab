# Civitas Lab v0.1.1

Civitas Lab v0.1.1 is a small patch release for the v0.1 spatial-cooperation
baseline. It improves extension points, aggregate reporting, and artifact
safety without changing the scientific scope of the published baseline.

## Highlights

- Binary payoff and local update-rule extension points for the spatial game
  engine.
- Across-replicate standard deviations in aggregate experiment CSV outputs.
- Hardened artifact validation and output preparation for symlinked paths.

## Assets

- `civitas-lab-0.1.1.jar`: self-contained Java 25 command-line application.
- `civitas-lab-0.1.1-results.tar.gz`: complete raw outputs for the frequency,
  kaleidoscope, and robustness experiments.
- `SHA256SUMS`: checksums for both release assets.

## Scientific Boundary

This patch release does not add new model-to-world claims. The v0.1 baseline
remains a narrow synchronous spatial evolutionary-game experiment with the
limitations documented in the ODD description, experiment protocol, and
limitations notes.
